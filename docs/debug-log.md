## LCD1602 只显示第一行乱码

**现象**

上电后第一行全是黑块，第二行空白。

**排查**

先量了 P0.4~P0.7 的波形，数据在发。查手册才发现 4 位模式的切换顺序有讲究。

HD44780 上电默认是 8 位模式。要切到 4 位模式，必须先发两次 `0x33`（软件复位，每次都用 8 位发），再发 `0x32`（切 4 位），之后才能用 4 位模式发指令。

我一开始直接发 `0x32`，芯片还停在 8 位模式，把 `0x32` 当成一条 8 位指令处理了，后面的字节全被当成指令的高低位，显示就乱了。

**解决**

```c
lcd_write_cmd(0x33);   // 复位
delay_ms(5);
lcd_write_cmd(0x33);
delay_ms(5);
lcd_write_cmd(0x32);   // 切 4 位
delay_ms(5);
lcd_write_cmd(0x28);   // 4 位、2 行、5x8 点阵
```

中间那 5 ms 不能省，芯片内部要时间。

## 按键一次触发多次

**现象**

按一下键，屏幕上输入两个字符。

**排查**

矩阵扫描是 20 ms 一次，按键按住超过 20 ms 就会被扫到多次。

**解决**

改成检测到按键后等松开再返回：

```c
uint8_t key_wait(void) {
    uint8_t k = key_scan();
    if (k == 0) return 0;
    delay_ms(20);              // 消抖
    if (key_scan() != k) return 0;   // 抖动，丢弃
    while (key_scan() != 0);   // 等松开
    return k;
}
```

阻塞式等松开，对这个系统没问题（不需要同时处理别的）。

## EEPROM 写入丢字节

**现象**

改密码后重启，密码变回旧的。

**排查**

打印读回来的值，发现写进去的是新密码，但下次上电读出来是旧值。

AT24C02 的写周期是 5 ms（内部擦写）。写完一个字节后如果不等待就写下一个，第二个会被忽略——芯片还在忙。

我原来是连续写 4 个字节：

```c
for (int i = 0; i < 4; i++) {
    i2c_write(addr + i, data[i]);   // 每次都发 STOP，然后立刻发下一个 START
}
```

**解决**

每写一个字节后加 5 ms 延时：

```c
for (int i = 0; i < 4; i++) {
    i2c_write(addr + i, data[i]);
    delay_ms(5);
}
```

更好的做法是页写（一次写 8 字节，只等一次），但 STC15 的 RAM 紧张，写缓冲要多占几个字节，就没做。

**顺便**

这个坑的教训：EEPROM 写不是「写完就完事」，要等内部擦写周期。AT24C02 是 5 ms，其他型号可能不同，得查手册。

## 舵机抖动

**现象**

舵机转到目标角度后一直在小幅抖动，嗡嗡响。

**排查**

示波器看 PWM 波形，发现周期不稳定，有时候 19 ms 有时候 21 ms。

原因是 Timer0 中断里直接算角度映射：

```c
void timer0_isr(void) interrupt 1 {
    static uint8_t cnt;
    cnt++;
    if (cnt < (uint8_t)(angle * 2.5 / 20)) {   // 浮点运算！
        SERVO = 1;
    } else {
        SERVO = 0;
    }
}
```

`angle * 2.5 / 20` 是浮点运算，51 上要几百个周期，把 100 µs 的中断拖长了。

**解决**

提前算好：

```c
static uint8_t s_ticks;   // 高电平持续多少个 100µs

void servo_set_angle(uint8_t deg) {
    if (deg > 180) deg = 180;
    // 0.5ms~2.5ms 对应 5~25 个 100µs
    s_ticks = 5 + (uint8_t)((uint16_t)deg * 20 / 180);
}

void timer0_isr(void) interrupt 1 {
    static uint8_t cnt;
    cnt++;
    if (cnt > 200) cnt = 1;          // 20 ms 周期
    SERVO = (cnt <= s_ticks) ? 1 : 0;   // 只做比较
}
```

中断从 200 多个周期降到 20 个以内，波形稳了，不抖了。

## 锁定时间重启就失效

**现象**

错误 5 次后锁定 3 分钟，但拔电再插上就能立刻重试，等于锁了个寂寞。

**排查**

失败次数只存在 RAM 变量里，掉电清零。锁定截止时刻也是 RAM 里的软时钟（用 Timer0 累加的毫秒计数）。

**解决**

- 失败次数写进 EEPROM（地址 0x07）
- 上电时检查：如果失败次数 ≥ 5，直接进锁定态
- 没有 RTC 就没法算真实剩余时间，所以上电后固定再锁 3 分钟

**注意**

不能每次失败都写 EEPROM——AT24C02 擦写寿命 100 万次，一天失败几次也扛不住几年。现在是「失败次数变化时才写」，而且加了个简单的均衡：写入前先读，值一样就不写。
