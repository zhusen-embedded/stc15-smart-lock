# 硬件调试记录

## 问题 1：LCD1602 只显示第一行乱码

**解决**：初始化改成 0x33 → delay 5ms → 0x32 → delay 5ms → 0x28。

## 问题 2：一次按键触发多次

**解决**：`key_wait()` 里等按键松开才返回，加 20 ms 消抖。

## 问题 3：EEPROM 写入丢字节

**解决**：`ee_write()` 末尾加 `delay_ms(5)` 等内部擦写周期。

## 问题 4：舵机抖动

**解决**：中断里只做比较，角度映射提前算好。

## 问题 5：锁定时间重启就失效

**现象**：错 5 次锁定了，拔电再插上又能立刻试密码。

**排查**：
- 失败次数只存在 RAM 变量里，掉电清零
- 锁定截止时刻也是 RAM 里的软时钟

**解决**：
- 失败次数写进 EEPROM（0x07）
- 锁定状态上电时检查：如果失败次数 ≥ 5，直接进锁定态
- 没有 RTC 就没法算真实剩余时间，所以上电后固定再锁 3 分钟

**结果**：拔电不能绕过锁定。
