# 硬件调试记录

## 问题 1：LCD1602 只显示第一行乱码

**解决**：初始化改成 0x33 → delay 5ms → 0x32 → delay 5ms → 0x28。

## 问题 2：一次按键触发多次

**解决**：`key_wait()` 里等按键松开才返回，加 20 ms 消抖。

## 问题 3：EEPROM 写入丢字节

**现象**：改密码后重启，新密码只存进去前两位，后面还是旧的。

**排查**：
- 逻辑分析仪抓 I2C，连续两次写之间只隔了 200 µs
- AT24C02 手册写明单字节写需要 5 ms 内部擦写周期，期间不响应

**解决**：
- `ee_write()` 末尾加 `delay_ms(5)`
- 更规范的做法是 ACK polling：写完反复发起始+地址，收到 ACK 说明写完了，比固定延时快

**结果**：连续写 6 位密码稳定。
