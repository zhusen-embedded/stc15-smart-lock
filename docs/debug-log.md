# 硬件调试记录

## 问题 1：LCD1602 只显示第一行乱码

**解决**：初始化改成 0x33 → delay 5ms → 0x32 → delay 5ms → 0x28。

## 问题 2：一次按键触发多次

**解决**：`key_wait()` 里等按键松开才返回，加 20 ms 消抖。

## 问题 3：EEPROM 写入丢字节

**解决**：`ee_write()` 末尾加 `delay_ms(5)` 等内部擦写周期。

## 问题 4：舵机抖动

**现象**：舵机转到一半会抽一下，同时 LCD 有轻微闪烁。

**排查**：
- 示波器看 P2.1 的 PWM，脉宽偶尔多出几十微秒
- 中断里做了浮点除法算角度映射，STC15 没有硬件浮点，一次除法要几百个周期
- 100 µs 的中断周期被拉长，脉宽跟着变

**解决**：
- `servo_set_angle()` 里用整数算好节拍数存起来
- 中断里只做一次比较和赋值

**结果**：PWM 脉宽稳定，舵机不抖了。
