# 硬件调试记录

## 问题 1：LCD1602 只显示第一行乱码

**现象**：上电后第一行全是黑块，第二行空白。

**解决**：初始化改成 0x33 → delay 5ms → 0x32 → delay 5ms → 0x28。

## 问题 2：一次按键触发多次

**现象**：输入 6 位密码，实际进去了十几位。

**排查**：
- 串口打印键值，发现按一次键连续返回 5~8 次同一个值
- 主循环跑得太快，按键按住期间每次扫描都命中

**解决**：
- `key_wait()` 里等按键松开才返回
- 加 20 ms 消抖，连续两次读到同一个键才算数

**结果**：按一次进一位。
